# Expense Reimbursement Scenarios

Status: accepted
Phase: P10
Checkpoint: BC19
Related ADR: `docs/adr/ADR-0004-second-domain-expense-reimbursement.md`

This directory introduces the second domain for the project: expense reimbursement.

The first domain-expansion pilot uses one scenario only:

- `ER01`: ambiguous receipt and approval evidence for an employee reimbursement claim.

The goal is to test whether the existing evidence-pack, Game Master boundary, action-proposal, validation, review, and claim-control structure can transfer beyond org-payment.

This is not a multi-domain baseline, statistical comparison, human behavior study, or real-world expense compliance claim.
